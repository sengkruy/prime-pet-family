# Prime Pet Family website

Open `index.html` in a browser to view the site. The website is a self-contained static build with no package installation or internet connection required.

## Included

- Responsive desktop and mobile layout
- Cat, dog, canned-food, and freeze-dried product filters
- Five data-driven product-detail views with ingredients, advantages and benefits
- Nine illustrated cat-and-dog care guides with veterinary reference links
- Product enquiry dialog that prepares an email to `info@primepetfamily.com`
- Seven-day feeding transition guide and FAQ
- Optimized web copies of the supplied product assets
- AI-generated lifestyle and educational support images

Product claims and feeding information should be checked against final production packaging before publication.
